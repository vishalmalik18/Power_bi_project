# ✈️ Airplane Crash Analysis Dashboard

## 📄 Project Overview

This project provides a detailed analysis of airplane crash data to uncover trends, causes, and patterns over the years. Using Power BI and DAX, the dashboard delivers interactive visualizations that help in understanding aviation accident statistics and their contributing factors.

---

## 📂 Project Files

* **project\_2.pbix** → Power BI dashboard file.
* **project\_2.pdf** → Exported report version for quick viewing.

---

## 📊 Features & Insights

* **Yearly trends** in airplane crashes.
* **Accident causes** breakdown by category.
* **Geographical distribution** of crashes.
* **Survivability statistics** over time.
* **Aircraft type & operator analysis**.

---

## 🛠 Tools & Technologies

* **Power BI** → For creating the dashboard and visuals.
* **DAX (Data Analysis Expressions)** → For advanced calculations and measures.
