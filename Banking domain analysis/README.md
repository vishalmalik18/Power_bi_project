# 🏦 Mitron - Credit Card Spend Analysis Dashboard (Power BI)

This repository contains a **Power BI dashboard** for analyzing **credit card spend patterns** across different demographics, payment types, cities, and time periods. The dashboard provides actionable insights for business analysts, marketing teams, and financial planners.


## 📈 Project Overview

The **Mitron Credit Card Spend Analysis Dashboard** provides visual exploration of:
- Payment methods preferences
- City-wise and gender-wise spend
- Category-wise spend (like Bills, Electronics, Travel)
- Spend by occupation and age group
- Monthly spending trends

---

## 🗂️ Features & Visualizations

| Feature                         | Visualization |
|---------------------------------|---------------|
| Payment Type %                  | Pie Chart     |
| Credit Card Spend by City       | Donut + Bar Chart |
| Spend by Gender                 | Bar Chart     |
| Spend by Category               | Horizontal Bar Chart |
| Occupation-wise Spend           | Bar Chart     |
| Age-wise Credit Card Usage      | Bar Chart     |
| Monthly Spend Trends            | Bar Chart     |
