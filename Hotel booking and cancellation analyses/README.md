# 🏨 Hotel Booking and Cancellation Analysis

## 📌 Project Overview
This project focuses on analyzing hotel booking data to understand patterns, identify factors affecting cancellations, and provide actionable insights to improve booking retention and operational efficiency.  
The analysis was performed using **Power BI** for visualization and **Python** for data preprocessing & exploration.

---

## 📂 Files in This Project
- **Hotel project.pbix** → Interactive Power BI dashboard for booking & cancellation analysis  
- **untitled.ipynb** → Jupyter Notebook containing Python-based EDA (Exploratory Data Analysis)  
- **hotel.booking.csv** → Raw dataset containing hotel booking details  
- **training_data.csv** → Additional dataset used for model building or feature analysis  

---

## 📊 Key Analysis & Insights
1. Cancellation rate comparison between different hotel types  
2. Seasonal trends in bookings and cancellations  
3. Impact of lead time on cancellation probability  
4. Effect of repeated guests on booking retention  
5. Revenue loss estimation due to cancellations  

---

## 🛠 Tools & Technologies Used
- **Power BI** – Data visualization & dashboard creation  
- **Python** (Pandas, NumPy, Matplotlib, Seaborn) – Data preprocessing & EDA
- **DAX (Data Analysis Expressions)** → For advanced measures and calculations in Power BI.
- **CSV datasets** – Source of booking & training data
