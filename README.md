# 📊 Power BI Projects

Welcome! 👋
This repository contains a collection of **Power BI dashboards and reports** designed to transform raw data into meaningful insights. Each project demonstrates **data cleaning, modeling, and visualization** to support better decision-making.

---

## 📂 Contents

* **Data Cleaning & Transformation** – Power Query for shaping and preparing data
* **Data Modeling** – Relationships, calculated columns, and DAX measures
* **Interactive Dashboards** – KPIs, charts, and slicers for dynamic analysis
* **Business Insights** – Turning data into actionable recommendations
* **Project Files** – `.pbix` reports and supporting datasets

---

## ⚙️ Tools & Technologies

* **Power BI Desktop** 📊
* **Power Query**
* **DAX (Data Analysis Expressions)**
* **Excel / CSV Datasets**
* **SQL (for some projects)**
