# 🚦 Road Accident Analysis

## 📌 Project Overview
This **Power BI** dashboard delivers an in-depth analysis of road accident data, uncovering trends in casualties, accident severity, vehicle involvement, and geographical distribution.  
The purpose is to identify high-risk patterns and generate actionable insights to enhance road safety measures.

---

## 📊 Dashboard Insights
- **Total CY Casualties:** 195.7K _(↓ 11.9% vs. previous year)_
- **Total CY Accidents:** 144.4K _(↓ 11.7%)_
- **Fatal Casualties:** 2.9K _(↓ 33.3%)_
- **Serious Casualties:** 27.0K _(↓ 16.2%)_
- **Slight Casualties:** 165.8K _(↓ 10.6%)_

### Key Breakdown:
- **Vehicle Type:** Cars dominate (155.8K), followed by Vans (15.9K), Bikes (15.6K), and Buses (6.6K).  
- **Location:** Urban (61.95%) vs Rural (38.05%).  
- **Light Condition:** Day (73.84%) vs Dark (26.16%).  
- **Road Type:** Mostly Single Carriageway (145K), then Dual (32K) and Roundabouts (13K).  
- **Map View:** UK accident hotspots visualized.

---

## 🛠 Tools & Technologies
- **Power BI** – Dashboard creation & visual analytics
- **DAX (Data Analysis Expressions)** – Measures & calculated fields
- **CSV Dataset** – Accident record source
